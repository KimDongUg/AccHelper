1 서비스 소개

AI Helper는 아파트, 오피스텔 등 공동주택 관리사무소를 위한 AI 관리사무소 서비스입니다. 입주민들의 관리비 조회, 민원 접수, 이주정산, 시설 이용 안내 등 반복적인 문의와 요청을 AI 챗봇과 전용 화면으로 24시간 자동 처리해 드립니다.

주요 기능

  • AI 챗봇 자동응대: 등록한 Q&A 데이터를 기반으로 입주민 문의에 자동으로 답변합니다.
  • 관리비 조회: 입주민이 본인 세대의 관리비 명세, 사용량, 단지 평균 비교, AI 분석까지 셀프로 확인할 수 있습니다.
  • 답변예약: 입주민이 직접 민원을 접수하고 답변 상태를 확인할 수 있습니다.
  • 우리아파트 당근: 중고거래·무료나눔·공동구매·분실물 등 입주민 전용 커뮤니티 장터를 제공합니다.
  • Q&A 데이터 관리: 관리자가 직접 질문과 답변을 등록, 수정, 삭제할 수 있습니다.
  • 통계/분석: 챗봇·민원·당근 이용 현황을 기간별 차트와 표로 확인할 수 있습니다.
  • 구독 관리: 14일 무료체험 후 월정액 구독으로 서비스를 이용합니다.

사용자 역할

역할설명권한

2 회사 등록하기

AI Helper 서비스를 처음 사용하시려면 먼저 회사를 등록해야 합니다. 회사 등록은 2단계로 진행됩니다.

접속 방법

메인 페이지(acchelper.kr)에서 "회사 등록" 버튼을 클릭합니다.

1단계: 회사 정보 입력

회사명관리업체의 이름 (예: OO아파트 관리사무소)필수

회사 코드시스템이 자동으로 생성 (수정 불가)자동생성

3 관리자 로그인

회사 등록이 완료되면 관리자 계정으로 로그인하여 서비스를 관리할 수 있습니다.

  • 구독이 활성화된 경우 → 관리자 대시보드로 이동
  • 구독이 미활성화된 경우 → 결제/구독 페이지로 이동
  • 수퍼관리자인 경우 → 수퍼관리 대시보드로 이동

아이디/비밀번호 찾기

로그인 화면 하단의 "아이디 찾기" 또는 "비밀번호 찾기" 링크를 클릭하면 등록된 정보를 통해 계정을 복구할 수 있습니다.

회원가입 (추가 관리자)

이미 등록된 회사에 새로운 관리자를 추가하려면 로그인 화면의 "회원가입" 링크를 클릭합니다. 이 경우 기존 회사의 회사번호가 필요합니다.

AI Helper는 월 구독 방식으로 운영됩니다. 처음 가입 시 14일 무료체험을 제공합니다.

무료체험 시작

1 결제 페이지 접속

로그인 후 구독이 없는 경우 자동으로 결제 페이지로 이동합니다.

2 "14일 무료체험 시작" 클릭

무료체험 버튼을 클릭하면 즉시 체험이 시작됩니다.

3 서비스 이용 시작

체험 시작 후 관리자 대시보드로 이동하여 Q&A를 등록하고 챗봇을 운영할 수 있습니다.

구독 결제

무료체험 기간이 만료되면 유료 구독을 통해 서비스를 계속 이용할 수 있습니다.

  • "구독 신청" 버튼 클릭 → 카드 정보 입력 (토스페이먼츠)
  • 매월 자동 결제 (등록한 카드로 청구)
  • 결제일: 최초 결제일 기준 매월 동일일자

구독 관리 기능

기능설명
카드 변경등록된 결제 카드를 다른 카드로 변경
구독 취소다음 결제일부터 구독 중지 (해당 월 끝까지 이용 가능)
결제 내역현재 플랜명, 카드 정보, 다음 결제일 확인

환불 정책: 최초 결제 후 7일 이내 전액 환불 가능합니다. 구독 취소 시 다음 달부터 해지됩니다.

6 Q&A 데이터 등록 및 관리

Q&A 데이터는 AI 챗봇이 입주민에게 응답할 때 사용하는 핵심 지식 데이터입니다. 정확하고 상세한 Q&A를 등록할수록 챗봇의 응답 품질이 향상됩니다.

Q&A 목록 화면

Q&A 관리 탭 화면

Q&A 관리 탭에서는 다음의 기능을 제공합니다:

  • 검색: 질문, 답변, 키워드로 Q&A 검색
  • 카테고리 필터: 이주정산, 관리비, 회계처리, 기타
  • 상태 필터: 활성/비활성 Q&A 필터링
  • 작성자 필터: 등록한 관리자별로 Q&A 필터링
  • 엑셀 다운로드: 현재 목록을 엑셀 파일로 내려받기
  • 페이지네이션: 10개씩 표시, 페이지 이동 가능

테이블 컬럼: ID, 카테고리, 질문, 답변(미리보기), 상태, 작성자, 수정일, 작업(수정/삭제)

새 Q&A 등록하기

1 "Q&A 추가" 버튼 클릭

Q&A 관리 탭 상단의 "Q&A 추가" 버튼을 클릭합니다.

2 Q&A 정보 입력

팝업 모달에서 다음 정보를 입력합니다:

입력 항목설명필수 여부
카테고리이주정산 / 관리비 / 회계처리 / 기타 중 선택필수
질문입주민이 자주 묻는 질문필수
답변질문에 대한 상세한 답변필수
키워드관련 검색 키워드 (쉼표로 구분)선택
활성 상태토글로 활성/비활성 설정 (비활성 시 챗봇에 미노출)필수
3 저장

"저장" 버튼을 클릭하면 Q&A가 등록되고 목록에 표시됩니다.

TIP: 질문 입력 시 시스템이 자동으로 중복 질문을 감지합니다. 유사한 질문이 이미 있는 경우 경고 메시지가 표시됩니다.

Q&A 수정하기

Q&A 목록에서 해당 항목의 "수정" 버튼을 클릭하면 등록 시와 동일한 모달이 열리며, 기존 데이터가 미리 채워져 있습니다. 내용을 수정한 후 "저장"을 클릭합니다.

Q&A 삭제하기

Q&A 목록에서 "삭제" 버튼을 클릭하면 확인 대화상자가 나타납니다. "확인"을 클릭하면 해당 Q&A가 영구 삭제됩니다.

주의: 삭제된 Q&A는 복구할 수 없습니다. 사용하지 않을 Q&A는 삭제 대신 "비활성" 상태로 변경하는 것을 권장합니다.

Q&A 작성 가이드

  • 질문은 구체적으로: "이주정산이란?" 보다는 "이주정산의 의미와 절차를 알려주세요"가 효과적입니다.
  • 답변은 상세하게: 핵심 정보를 빠짐없이 포함하세요. 답변이 상세할수록 AI 응답 품질이 높아집니다.
  • 키워드 활용: 입주민이 검색할 수 있는 다양한 키워드를 등록하세요 (예: 이사, 이주, 전출, 퇴거).
  • 카테고리 분류: 적절한 카테고리를 선택하면 챗봇이 더 정확한 답변을 제공합니다.

7 관리비 조회 서비스

입주민이 본인 세대의 관리비 명세, 사용량, 단지 평균과의 비교, AI 분석까지 셀프로 확인할 수 있는 기능입니다. ERP 수집기(AIHelperCollector)로 관리비 데이터가 연동된 회사에서만 상단 메뉴에 "관리비 조회"가 표시됩니다.

7-1. 입주민 - 관리비 조회 방법

1 "관리비 조회" 메뉴 접속

2 "인증번호 받기" 클릭

해당 세대에 등록된 휴대폰 번호로 SMS 인증번호(OTP)가 발송됩니다.

3 인증번호 입력 및 조회

받은 인증번호를 입력하면 이번 달 관리비 내역이 화면에 표시됩니다.

개인정보 수집·이용 동의: 최초 조회 시 1회 동의하면 되며, 월 1회 재동의가 필요할 수 있습니다.

조회 결과 화면 구성

영역설명
이번 달 관리비동/호수, 부과월, 총 관리비, 지난달 대비 증감액·증감률 표시
관리비 구성 (도넛차트)일반관리·전기/에너지·수도/온수·장기수선·냉난방·기타 등 항목별 금액과 비중. 항목 클릭 시 세부 내역 펼쳐보기
사용량 분석전기(kWh)·수도(톤)·온수(톤)·냉방(Mcal) 사용량과 단가, 검침 시작→종료 지침, 동일 전용면적 평균 대비 게이지
단지 비교 분석관리비·전기·수도·온수 항목을 "우리집"과 "동일면적 평균"으로 막대그래프 비교
월별 관리비 추이데이터가 3개월 이상 누적되면 월별 추이 그래프로 표시 (그 전까지는 누적 안내 문구 표시)
AI 분석전월 대비 증감 사유, 환급 예정 항목(장기수선충당금 등) 같은 자동 인사이트 코멘트
상세 고지서 보기항목별 부과내역 전체를 표로 펼쳐서 확인

주의: 인증번호는 관리사무소에 등록된 휴대폰 번호로만 발송됩니다. 번호가 변경되었거나 인증번호를 받지 못한 경우 관리사무소로 문의해야 합니다.

7-2. 관리자 - 관리비 조회 관리

대시보드의 "관리비 조회" 탭(관리비 데이터가 연동된 회사에만 표시)에서 다음 기능을 제공합니다.

기능설명
세대 직접 조회동/호수를 입력해 인증 절차 없이 입주민 화면과 동일한 관리비 내역을 바로 확인

조회 이력최근 조회 요청 목록과 성공/실패 여부, 실패 시 실패 단계를 비고란에 표시

TIP: 관리비 원본 데이터는 ERP 수집기(AIHelperCollector) 프로그램이 관리사무소 ERP에서 자동으로 수집해 연동합니다. 대시보드 상단의 "ERP 수집기 다운로드" 카드에서 최신 버전을 내려받을 수 있습니다.

챗봇 접속 방법

입주민 (비로그인)

1 acchelper.kr 접속

메인 페이지에서 승인된 회사 목록이 표시됩니다.

3 질문하기

관리자

AI 챗봇 화면
  • 상단 메뉴: AI 챗봇 / 관리비 조회 / 답변예약 / 우리아파트 당근 (회사별로 활성화된 메뉴만 표시)
  • 히어로 영역: 회사명 + AI Helper 인사말 (공지사항 활성화 시 공지 문구로 대체)
  • 빠른 질문 버튼: 관리자가 회사 설정에서 지정한 카테고리 버튼 (클릭 시 자동 질문)

  • 입력창: 하단에 질문 입력란과 전송 버튼

AI 답변 구조

  • AI 답변: Q&A 데이터를 기반으로 생성된 자연스러운 답변
  • 참고 자료: 답변에 사용된 원본 Q&A 목록 (접기/펼치기 가능)
  • 피드백: 답변 유용도 평가 (좋아요/싫어요 버튼, 관리자 대시보드 "피드백" 탭에서 확인 가능)

TIP: 챗봇의 응답 품질은 등록된 Q&A 데이터의 양과 질에 비례합니다. 더 많은 Q&A를 등록할수록 정확한 답변을 제공합니다. AI가 답변하지 못한 질문은 대시보드 "미답변 질문" 탭에 쌓이므로 주기적으로 확인해 Q&A로 등록하세요.

TIP: 비밀번호 변경은 선택사항입니다. 비밀번호 필드를 비워두면 기존 비밀번호가 유지됩니다.

14 자주 묻는 질문 (FAQ)

Q. 회사 등록 후 바로 챗봇을 사용할 수 있나요?

A. 회사 등록 후 수퍼관리자의 승인이 필요합니다. 승인 전에도 관리자 로그인, Q&A 등록은 가능하지만, 입주민에게 챗봇이 공개되려면 승인이 완료되어야 합니다.

Q. 무료체험 기간 중 해지하면 비용이 발생하나요?

A. 아닙니다. 14일 무료체험 기간 내 해지하면 비용이 전혀 발생하지 않습니다.

Q. Q&A는 몇 개까지 등록할 수 있나요?

A. 등록 가능한 Q&A 수에 제한은 없습니다. 더 많은 Q&A를 등록할수록 AI 챗봇의 응답 품질이 향상됩니다.

Q. 입주민이 챗봇을 사용하려면 로그인이 필요한가요?

A. 아닙니다. 입주민은 로그인 없이 회사를 선택한 후 바로 챗봇을 이용할 수 있습니다. 관리비 조회, 민원 접수, 당근 이용 시에는 동/호수 기반의 간편 인증만 거치면 됩니다.

Q. 관리비 조회 인증번호가 오지 않아요.

A. 인증번호는 관리사무소에 등록된 휴대폰 번호로만 발송됩니다. 번호가 변경되었거나 문자가 오지 않는다면 관리사무소(관리자)에 문의해 등록 번호를 확인해 주세요.

Q. 관리비 조회에서 "월별 관리비 추이"가 안 보여요.

A. 관리비 추이 그래프는 최소 3개월치 데이터가 누적되어야 표시됩니다. 그 전까지는 누적 안내 문구가 대신 표시됩니다.

Q. 민원을 올리면 답변은 언제 받을 수 있나요?

A. 관리사무소 담당자가 확인 후 게시판에 직접 답변을 등록합니다. 답변이 등록되면 목록에 "답변완료"로 표시됩니다. 처리 기간은 관리사무소 사정에 따라 다를 수 있습니다.

Q. 우리아파트 당근 게시글은 아무나 볼 수 있나요?

A. 게시글 열람 및 작성에는 동/호수·이름·전화번호를 입력하는 입주민 인증(관리자 승인)이 필요합니다. 게시글에는 이름·전화번호 없이 동/호수만 공개됩니다.

Q. 관리자를 여러 명 등록할 수 있나요?

A. 네. 관리자 관리 탭(최고관리자 전용)에서 추가 관리자를 등록할 수 있으며, 관리자/뷰어 등 역할을 지정할 수 있습니다.

Q. 삭제한 Q&A를 복구할 수 있나요?

A. 삭제된 Q&A는 복구할 수 없습니다. 사용하지 않을 Q&A는 삭제 대신 "비활성" 상태로 변경하시는 것을 권장합니다.

Q. 결제 수단을 변경하고 싶어요.

A. 구독/결제 페이지에서 "카드 변경" 버튼을 클릭하면 새로운 카드를 등록할 수 있습니다.
